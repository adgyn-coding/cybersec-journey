# Cybersecurity Learning Journey

This repository documents a hands-on journey into web security and secure software development.

## How I learn

- Learn the concept and why it matters.
- Practice only in local learning labs or on systems with explicit authorization.
- Explain the root cause and learn how to fix it.
- Keep personal learning notes in my own words.

## Repository

- `journal/` — learning notes written in my own words.
- `labs/` — safe exercises and labs using fake data.

## Safety

Labs are for authorized learning only. Run intentionally vulnerable labs on `127.0.0.1` with fake data; never expose them to the public internet or a LAN. Each intentionally vulnerable lab must display `INTENTIONALLY VULNERABLE - LOCAL USE ONLY`.

Never publish secrets, real personal data, findings about third-party systems, private progress notes, lab solutions, or gate-test material. Test other systems only with explicit authorization and a clearly defined scope.
